# ADR-005. Формат загрузки справочника сотрудников

ADR (Architecture Decision Record) фиксирует выбор между альтернативами, обоснование и последствия.

## Контекст и постановка проблемы

Система должна идентифицировать сотрудников по номерам пропусков. Источник данных о сотрудниках не указан, требуется выбрать способ импорта справочника.

## Статус

**ПРЕДЛОЖЕНО** | ПРИНЯТО | ЗАМЕНЕНО

## Альтернативы

### Вариант 1. Загрузка из CSV-файла

Плюсы:

- Простота формата, легко генерируется из HR-систем
- Не требует разработки сложного API для интеграции
- Легко обновлять данные вручную или скриптом

Минусы:

- Данные не обновляются в реальном времени
- Риск ошибок при ручном формировании файла

### Вариант 2. Интеграция с HR-системой через API

Плюсы:

- Автоматическое обновление данных
- Высокая актуальность справочника

Минусы:

- Сложность реализации и поддержки интеграции
- Зависимость от доступности HR-системы
- Не указано в ограничениях проекта

## Принятое решение

Использовать загрузку справочника сотрудников из CSV-файла. Формат файла: CSV. Это решение зафиксировано в допущениях (ASM-01, ASM-03) и ограничениях.

## Последствия принятого решения

- Администратор системы должен регулярно загружать актуальный файл
- Реализована валидация формата файла при загрузке
- При ошибке импорта транзакция откатывается

## Ответственные

- Системный аналитик
- Администратор системы

Связано: FR-11

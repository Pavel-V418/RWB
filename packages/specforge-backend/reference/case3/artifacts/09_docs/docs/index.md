# Система учёта выдачи и возврата инструмента

**Цифровая система контроля выдачи и возврата дорогостоящего инструмента для технических служб.**

## Проблема

Сейчас учёт инструмента ведётся в бумажных журналах, что приводит к потере оборудования и невозможности быстро определить его местонахождение. Отсутствие цифрового контроля создаёт риски хищения и простоя из-за незнания доступности инструмента. Бумажный учёт не позволяет интегрировать данные с корпоративными системами учёта ТМЦ.

## Для кого

- Кладовщики, выдающие и принимающие инструмент
- Руководители складов, управляющие каталогом и контролем возвратов
- Сотрудники технических служб, использующие инструмент
- Администраторы системы, настраивающие интеграции и справочники

## Ценность

- Полная прозрачность местонахождения каждого единицы инструмента в реальном времени
- Исключение потерь за счёт обязательной фиксации выдачи и возврата с оценкой состояния
- Автоматическая передача данных о движении ТМЦ в корпоративную систему учёта
- Возможность работы кладовщика без интернета с последующей синхронизацией данных
- Контроль сроков возврата и автоматическое формирование списка невозвращённого инструмента

## Возможности

| Возможность | Что делает | Требования |
| --- | --- | --- |
| Управление каталогом инструмента | Добавление позиций, присвоение инвентарных номеров и генерация QR-кодов для идентификации. | FR-1, FR-2, FR-12 |
| Выдача и возврат инструмента | Сканирование QR-кодов и пропусков для фиксации выдачи, возврат с оценкой состояния (исправен, ремонт, утеря). | FR-3, FR-6, FR-17 |
| Бронирование и контроль доступности | Заблаговременное бронирование инструмента на дату и автоматический запрет выдачи забронированного другим сотрудникам. | FR-4, FR-5, FR-13, FR-14 |
| Контроль сроков и история | Мониторинг сроков возврата, формирование списка просроченных позиций и просмотр полной истории движения. | FR-7, FR-9, FR-16 |
| Интеграция и офлайн-режим | Передача событий в систему учёта ТМЦ через Kafka, работа мобильного приложения без связи и синхронизация данных. | FR-8, FR-10, FR-15 |
| Управление справочниками | Загрузка списка сотрудников и номеров пропусков из внешнего файла для идентификации пользователей. | FR-11 |

## Цели

- Предотвратить потерю инструмента и обеспечить прозрачность его местонахождения
- Заменить бумажный журнал учёта на цифровую систему

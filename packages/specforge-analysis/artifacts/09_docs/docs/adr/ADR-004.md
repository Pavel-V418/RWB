# ADR-004. Источник времени окончания оплаты

ADR (Architecture Decision Record) фиксирует выбор между альтернативами, обоснование и последствия.

## Контекст и постановка проблемы

Реальной оплаты нет, но система должна показывать «Парковка оплачена до 15:20».

## Статус

**ПРЕДЛОЖЕНО** | ПРИНЯТО | ЗАМЕНЕНО

## Альтернативы

### Вариант 1. длительность выбирает водитель, paidUntil возвращает mock поставщика

Плюсы:

- прототип работает без доступа к оплате
- единая логика для запуска и продления

Минусы:

- точность зависит от ввода водителя

### Вариант 2. время только из API поставщика

Плюсы:

- точные данные

Минусы:

- невозможно без промышленного доступа

## Принятое решение

Вариант 1 (принят по умолчанию на вопрос Q-02): при запуске водитель выбирает длительность, при подтверждении — время окончания.

## Последствия принятого решения

- После подключения реального поставщика paidUntil будет приходить из его API без изменения интерфейса

## Ответственные

- Системный аналитик
- Архитектор

Связано: Q-02, FR-14, FR-19

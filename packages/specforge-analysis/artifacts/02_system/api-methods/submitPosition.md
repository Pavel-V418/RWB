## 1. Назначение

Передать координату автомобиля; ответ содержит определённую зону и переход.

Транспорт: HTTPS (TLS 1.2+), HTTP/1.1. Схема взаимодействия: синхронный запрос — ответ. Формат тела: JSON, UTF-8.

## 2. Входные данные (Входящие параметры)

### Авторизация

JWT в заголовке `Authorization: Bearer <token>`; роль пользователя берётся из claims токена.

### Заголовки

| Наименование | Описание | Тип данных | Обязательность | Пример |
| --- | --- | --- | --- | --- |
| Authorization | токен доступа | string | да | `Bearer eyJhbGciOi…` |
| Content-Type | формат тела запроса | string | да | `application/json` |
| X-Correlation-Id | сквозной идентификатор запроса; если не передан — генерируется сервером | string | нет | `req-20261030-0001` |

### Параметры path

| Наименование | Описание | Тип данных | Обязательность | Пример |
| --- | --- | --- | --- | --- |
| vehicleId | идентификатор ресурса | string (uuid) | да | `3fa85f64-5717-4562-b3fc-2c963f66afa6` |

### Параметры query

Отсутствуют.

### Модель данных тела запроса

| Поле | Описание | Тип данных | Обязательность | Варианты значений | Поле БД |
| --- | --- | --- | --- | --- | --- |
| point | координата | object (GeoJSON Point) | да | — | `vehicle_positions.point` |
| recordedAt | время фиксации на устройстве | string (date-time, ISO 8601) | да | — | `vehicle_positions.recorded_at` |

## 4. Описание алгоритма работы метода

**Основной сценарий:**

1. Проверить, что автомобиль закреплён за водителем из токена
2. Проверить координаты, recordedAt (не позже now + 5 мин) и точность
3. Если точка с тем же recordedAt уже есть — вернуть сохранённый результат
4. Найти зону ST_Contains по GIST-индексу; точки с точностью хуже 100 м зону не меняют
5. Сравнить с двумя последними точками: при смене зоны записать ParkingEvent и outbox в одной транзакции
6. Обновить Vehicle.currentZoneId и lastPositionAt
7. Вернуть zoneId, zoneNumber, transition и текст уведомления

**Сценарий исключений:**

- Чужой автомобиль → 403 vehicle-not-assigned
- Автомобиль не найден → 404
- recordedAt в будущем более чем на 5 минут → 422 position-from-future
- Координаты вне диапазона → 400
- Превышен лимит частоты → 429

**Проверки и валидации:**

- `accuracyM`: ≥ 0; ≤ 10000
- `speedKmh`: ≥ 0; ≤ 300
- `source`: `gps`, `mock`; по умолчанию `gps`, обязательно

**Кэширование:** не применяется.

**Производительность:** ограничение частоты запросов, превышение — 429 и `Retry-After`; таймаут обработки 30 с.

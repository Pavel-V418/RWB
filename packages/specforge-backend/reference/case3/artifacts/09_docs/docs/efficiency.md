# Эффективность конвейера

Расход по этапам из `metrics.jsonl` (строка на каждый вызов LLM). Вызовы из кэша и эталонных фикстур отмечены отдельно и не отражают реальную модель.

| Этап | Вызовов | Повторов | Из кэша / фикстур | Токены вход | Токены выход | Время LLM, с |
| --- | --- | --- | --- | --- | --- | --- |
| **Итого** | 0 | 0 | 0 | 0 | 0 | 0 |

!!! warning "Ожидается: метрики этапов"
    Раздел заполнится автоматически, когда каждый этап положит результат в `artifacts/<этап>/metrics.jsonl`, и этап документации будет перезапущен.

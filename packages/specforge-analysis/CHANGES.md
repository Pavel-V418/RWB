# Изменения по итогам аудита

## Устойчивость (конвейер не останавливается на мелочах)
- DDL: зарезервированные слова PostgreSQL (`order`, `from`, `end`…) в именах таблиц, колонок и enum-типов берутся в кавычки; предупреждение `W_DDL_RESERVED_NAME`.
- Пути API: словарь «глагол → существительное» покрывает все глаголы из `PATH_VERBS` (`start/stop/run/send/mark/open/read/set…`); лишний глагол (`POST /orders/create`) убирается только при совпадающем HTTP-методе.
- Роли на этапе 2 сопоставляются по ключу, имени, `ROLE-` и синонимам; если ролей не осталось — берутся из акторов FR (`W_ROLE_MAPPED`, `W_ROLE_FROM_FR`).
- Сбой модели → `GateResult` с `E_LLM` и `gate_result.json`, а не исключение; результаты прошлого прогона удаляются в начале этапа.
- `finish_reason=length` → повтор с лимитом ×1,5, на последнем повторе без thinking; обрезанный ответ не добавляется в диалог.
- Новый ремонтный проход этапа 2 (`repair_design_N`, 0–2 вызова) для блокирующих ошибок шлюза: пути, роли, жизненные циклы, enum, regex, дубли, DDL.
- Исправлено падение этапа 2, когда `sa_prose` недоступен (`prose is None`).

## Честность трассировки
- Связи BR → FR, подобранные кодом по словам, записываются как `fr_candidates` («кандидат»), не засчитываются в покрытие и остаются в `W_BR_UNCOVERED`.
- Нечёткий поиск цитат требует совпадения всех чисел и указывает строку с наибольшим совпадением; `W_FUZZY_SOURCE` — для всех коллекций.
- Открытый `blocker` критика → `W_CRITIC_BLOCKER`; статус `repaired` заменён на `repair_attempted`.

## Мелкие баги
- Интерактивный режим: пустой ответ в `answers.yaml` = вариант по умолчанию (раньше — бесконечный код 3).
- Ответы заказчика передаются в ремонт критериев приёмки затронутых FR (`W_ANSWER_NO_FR`, если FR не указаны).
- `.docx`: абзацы и таблицы читаются в порядке документа.
- `rehearse`: статус с кодами ошибок, сообщение о сбое модели, коды выхода 0/1/2 (раньше «нужна модель» = успех).
- Regex проверяется на совместимость с ECMA-262 (`(?P<…>)`, `\A`, `(?i)`, possessive, POSIX-классы).
- Метрика `retries` считает все неуспешные ответы модели, включая обрезанные.

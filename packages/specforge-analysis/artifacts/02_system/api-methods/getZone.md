## 1. Назначение

Карточка зоны.

Транспорт: HTTPS (TLS 1.2+), HTTP/1.1. Схема взаимодействия: синхронный запрос — ответ. Формат тела: JSON, UTF-8.

## 2. Входные данные (Входящие параметры)

### Авторизация

JWT в заголовке `Authorization: Bearer <token>`; роль пользователя берётся из claims токена.

### Заголовки

| Наименование | Описание | Тип данных | Обязательность | Пример |
| --- | --- | --- | --- | --- |
| Authorization | токен доступа | string | да | `Bearer eyJhbGciOi…` |
| X-Correlation-Id | сквозной идентификатор запроса; если не передан — генерируется сервером | string | нет | `req-20261030-0001` |

### Параметры path

| Наименование | Описание | Тип данных | Обязательность | Пример |
| --- | --- | --- | --- | --- |
| zoneId | идентификатор ресурса | string (uuid) | да | `3fa85f64-5717-4562-b3fc-2c963f66afa6` |

### Параметры query

Отсутствуют.

### Модель данных тела запроса

Тело запроса отсутствует.

### Пример запроса

```http
GET /api/v1/zones/3fa85f64-5717-4562-b3fc-2c963f66afa6 HTTP/1.1
Host: localhost:8080
Authorization: Bearer <token>


```

### Кому разрешено вызывать метод

- Водитель (`driver`)
- Диспетчер (`dispatcher`)

Остальным ролям — ответ 403.

## 3. Выходные данные (Исходящие параметры)

### Успешная обработка запроса

| HTTP Code | Описание | Возвращаемая информация |
| --- | --- | --- |
| 200 | Запрос успешно обработан | object |

#### Модель данных тела ответа

Формат: объект.

| Поле | Описание | Тип данных | Обязательность | Поле БД / ограничения |
| --- | --- | --- | --- | --- |
| id | — | string (uuid) | да | `parking_zones.id`; — |
| zoneNumber | номер зоны | string | да | `parking_zones.zone_number`; до 4 симв.; regex `^\d{4}$` |
| name | название или адресный ориентир | string | нет | `parking_zones.name`; до 200 симв. |
| boundary | границы зоны | object (GeoJSON Polygon) | да | `parking_zones.boundary`; — |
| hourlyRate | стоимость часа, руб. | number | нет | `parking_zones.hourly_rate`; ≥ 0; ≤ 10000 |
| paidHours | часы платного режима, например «пн–пт 08:00–20:00» | string | нет | `parking_zones.paid_hours`; до 100 симв. |
| maxDurationMinutes | ограничение длительности стоянки | integer | нет | `parking_zones.max_duration_minutes`; ≥ 1; ≤ 1440 |
| dataSource | источник геоданных | string (enum) | да | `parking_zones.data_source`; `open_data`, `demo`; по умолчанию `open_data` |
| dataVersion | версия или дата снимка данных | string | нет | `parking_zones.data_version`; до 50 симв. |
| createdAt | время создания | string (date-time, ISO 8601) | да | `parking_zones.created_at`; — |
| updatedAt | время изменения | string (date-time, ISO 8601) | да | `parking_zones.updated_at`; — |

Необязательное поле без значения возвращается как `null`; пустой список — `[]`.

### Неуспешная обработка запроса

| HTTP Code | Описание |
| --- | --- |
| 400 | Ошибка валидации запроса |
| 401 | Нет или истёк токен доступа |
| 403 | Недостаточно прав для операции |
| 404 | Ресурс не найден: Зона не найдена |
| 429 | Превышен лимит запросов |
| 500 | Внутренняя ошибка |

#### Модель данных тела ответа (application/problem+json, RFC 9457)

| Поле | Описание | Тип данных | Обязательность |
| --- | --- | --- | --- |
| type | URI типа ошибки | string | да |
| title | краткое описание для пользователя | string | да |
| status | HTTP-код | integer | да |
| detail | подробности | string | нет |
| code | машиночитаемый код бизнес-ошибки | string | нет |
| traceId | идентификатор для поиска в логах | string | нет |
| errors | ошибки валидации: `{"поле": ["сообщение"]}` | object | нет |

## 4. Описание алгоритма работы метода

**Основной сценарий:**

1. Найти зону по zoneId и вернуть карточку

**Сценарий исключений:**

- Зона не найдена → 404

**Кэширование:** не применяется.

**Производительность:** таймаут обработки 30 с.

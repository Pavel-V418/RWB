Вопросов: 5 (лимит 5). Остальные неоднозначности закрыты допущениями — см. `requirements.md`, раздел «Допущения».

## Q-01. Аутентификация

Как входят водители и диспетчеры: собственные учётные записи или корпоративный SSO?

Влияние: security, критичность: high. Затрагивает: FR-15, FR-16.

Варианты:

- Собственные учётные записи, JWT, роли водитель и диспетчер (по умолчанию)
- Корпоративный SSO по OpenID Connect

Статус: принято умолчание. Ответ: Собственные учётные записи, JWT, роли водитель и диспетчер

## Q-02. Источник времени окончания оплаты

Реальная оплата не выполняется, но система должна показывать «Парковка оплачена до 15:20». Откуда система узнаёт время окончания?

Влияние: architecture, критичность: high. Затрагивает: FR-5, FR-9, FR-14, FR-19.

Варианты:

- Водитель выбирает длительность при запуске, mock-поставщик возвращает paidUntil (по умолчанию)
- Водитель вручную вводит время окончания уже оплаченной парковки
- Время окончания берётся только из API поставщика

Статус: принято умолчание. Ответ: Водитель выбирает длительность при запуске, mock-поставщик возвращает paidUntil

## Q-03. Где определяется зона

Вход и выход из зоны вычисляются на сервере по потоку координат или на устройстве?

Влияние: architecture, критичность: high. Затрагивает: FR-2, FR-7, FR-8, FR-13.

Варианты:

- На сервере (PostGIS), устройство только передаёт координаты (по умолчанию)
- На устройстве по загруженным полигонам, сервер получает события

Статус: принято умолчание. Ответ: На сервере (PostGIS), устройство только передаёт координаты

## Q-04. Автоматический старт сессии

Сессия начинается автоматически при въезде в зону или только после действия водителя?

Влияние: core_scenario, критичность: high. Затрагивает: FR-13, FR-19.

Варианты:

- Только после подтверждения водителем; при въезде — уведомление (по умолчанию)
- Автоматически при въезде с возможностью отмены

Статус: принято умолчание. Ответ: Только после подтверждения водителем; при въезде — уведомление

## Q-05. Источник геоданных зон

Использовать снимок открытых данных Санкт-Петербурга или демонстрационный набор зон?

Влияние: data, критичность: high. Затрагивает: FR-21, FR-2.

Варианты:

- Снимок открытых данных в seed-файле GeoJSON (по умолчанию)
- Демонстрационный набор из нескольких зон
- Загрузка из внешнего источника при каждом запуске

Статус: принято умолчание. Ответ: Снимок открытых данных в seed-файле GeoJSON

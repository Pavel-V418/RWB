# ADR-002. Защита от дрожания GPS на границе зоны

ADR (Architecture Decision Record) фиксирует выбор между альтернативами, обоснование и последствия.

## Контекст и постановка проблемы

GPS на границе зоны «дрожит», и каждая ложная точка порождала бы уведомление.

## Статус

**ПРЕДЛОЖЕНО** | ПРИНЯТО | ЗАМЕНЕНО

## Альтернативы

### Вариант 1. фиксировать вход и выход по первой точке

Плюсы:

- самая быстрая реакция

Минусы:

- поток ложных уведомлений на границе

### Вариант 2. две подряд точки и отсев неточных

Плюсы:

- нет ложных уведомлений
- простая реализация

Минусы:

- уведомление приходит на одну точку позже

### Вариант 3. буфер в метрах вокруг полигона

Плюсы:

- учитывает геометрию

Минусы:

- сложнее настроить для смежных зон

## Принятое решение

Вариант 2: вход и выход фиксируются после двух подряд точек; точки с точностью хуже 100 м не меняют зону.

## Последствия принятого решения

- Задержка уведомления — один интервал передачи координат
- Число подряд точек настраивается

## Ответственные

- Системный аналитик
- Архитектор

Связано: RISK-01, FR-7, AC-FR-7-02

# Правила дизайн-системы (PrimeNG 20) — для промптов агентов

Короткий файл, целиком попадает в кэшируемый префикс промпта UX- и frontend-агентов.

1. **Только компоненты из `kit-manifest.json`.** Нет `<button>`, `<select>`, `<table>`, `<dialog>`. `<input>` — только с `pInputText`, `<textarea>` — только с `pTextarea`. Устаревшие `p-dropdown`, `p-calendar`, `p-inputSwitch`, `p-sidebar`, `p-tabView` запрещены: используй `p-select`, `p-datepicker`, `p-toggleswitch`, `p-drawer`, `p-tabs`.
2. **Цвета — только токены.** Никаких `#hex`, `rgb()`, `hsl()` в компонентах. Статусы — через `severity` (`success | info | warn | danger | secondary | contrast`). Текст второго плана — `var(--p-text-muted-color)`.
3. **Отступы — шкала 4/8/12/16/24/32** (`var(--sf-space-1..6)`). Раскладка — классы из `layout.scss`: `sf-stack`, `sf-row`, `sf-grid`, `sf-page`.
4. **У каждого экрана 5 состояний**: загрузка (`p-skeleton` в форме будущего контента), пусто (`<app-state kind="empty">` + действие, если оно есть), ошибка (`p-message severity="error"` + «Повторить»), нет доступа (`p-message severity="warn"`), данные. Состояния переключает `<app-state>`, а не ручные `*ngIf`/`@if` в каждом компоненте.
5. **Одно главное действие на экран** (`p-button` без severity), остальные `severity="secondary"` или `[text]="true"`. Опасное действие — `severity="danger"` и подтверждение через `ConfirmationService`.
6. **Обратная связь на каждое действие:** `[loading]` на кнопке во время запроса, toast с результатом (`MessageService`), ошибки валидации — под полем (`<small class="sf-error">`), общая ошибка — `p-message` над формой.
7. **Подписи полей — над полем** (`<label for>`), обязательные помечены `*`. Плейсхолдер не заменяет подпись.
8. **Таблицы:** серверная пагинация (`[lazy]`), `dataKey="id"`, `rowHover`, статусы — `p-tag`, даты — пайп `sfDate`, длительности — `sfDuration`. На узких экранах колонки с `hideBelow` скрываются.
9. **Адаптивность:** брейкпоинты `sm 576 / md 768 / lg 1024 / xl 1280`. На `< md` меню уходит в `p-drawer`, таблица — в карточки, карта — на всю ширину, боковая панель — под карту.
10. **Тексты интерфейса — на русском**, краткие, в повелительном наклонении для действий («Сохранить», «Начать сессию»). Время — `HH:mm`, даты — `dd.MM.yyyy`, часовой пояс пользователя.
11. **Доступность:** у кнопок-иконок `ariaLabel` и `pTooltip`, контраст по токенам, фокус не убирать, у каждого интерактивного элемента `data-testid` из спеки (`<screen>-<element>`).
12. **Импорт:** standalone-компоненты, модули PrimeNG импортируются в `imports: [...]` компонента. Состояние — `signal()`/`computed()`, подписки — `takeUntilDestroyed()`.

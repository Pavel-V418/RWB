# ADR-004. Определение срока возврата инструмента

ADR (Architecture Decision Record) фиксирует выбор между альтернативами, обоснование и последствия.

## Контекст и постановка проблемы

Не было указано, как именно рассчитывается срок возврата. Необходимо определить логику для формирования списка невозвращённого инструмента и отправки уведомлений.

## Статус

**ПРЕДЛОЖЕНО** | ПРИНЯТО | ЗАМЕНЕНО

## Альтернативы

### Вариант 1. Фиксированный период от даты выдачи (N дней)

Плюсы:

- Простота расчета
- Гибкость: N можно настроить для разных категорий инструмента
- Не зависит от даты бронирования, которая может не совпадать с фактической выдачей

Минусы:

- Не учитывает длительность запланированных работ, если они превышают N дней

### Вариант 2. Срок по дате бронирования

Плюсы:

- Совпадает с планом работ сотрудника
- Логично для долгосрочных бронирований

Минусы:

- Сложность: дата бронирования может быть изменена или отсутствовать при срочной выдаче
- Необходимость синхронизации данных бронирования с фактической выдачей

## Принятое решение

Срок возврата рассчитывается как дата выдачи плюс N дней, где N является настраиваемым параметром. По умолчанию N = 1 день. Это решение зафиксировано в допущениях (ASM-02, ASM-07).

## Последствия принятого решения

- В системе настраивается параметр N для расчёта срока
- Система периодически проверяет статусы выданных инструментов на предмет истечения срока
- Формируется список невозвращённого инструмента для руководителя склада

## Ответственные

- Системный аналитик
- Бизнес-аналитик

Связано: FR-7, FR-16, Q-02

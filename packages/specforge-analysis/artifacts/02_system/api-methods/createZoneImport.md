## 1. Назначение

Загрузить зоны из GeoJSON (снимок открытых данных или демо-набор).

Транспорт: HTTPS (TLS 1.2+), HTTP/1.1. Схема взаимодействия: синхронный запрос — ответ. Формат тела: JSON, UTF-8.

## 2. Входные данные (Входящие параметры)

### Авторизация

JWT в заголовке `Authorization: Bearer <token>`; роль пользователя берётся из claims токена.

### Заголовки

| Наименование | Описание | Тип данных | Обязательность | Пример |
| --- | --- | --- | --- | --- |
| Authorization | токен доступа | string | да | `Bearer eyJhbGciOi…` |
| Content-Type | формат тела запроса | string | да | `application/json` |
| X-Correlation-Id | сквозной идентификатор запроса; если не передан — генерируется сервером | string | нет | `req-20261030-0001` |

### Параметры path

Отсутствуют.

### Параметры query

Отсутствуют.

### Модель данных тела запроса

| Поле | Описание | Тип данных | Обязательность | Варианты значений | Поле БД |
| --- | --- | --- | --- | --- | --- |
| dataSource | источник геоданных | string (enum) | да | `open_data`, `demo`; по умолчанию `open_data` | `parking_zones.data_source` |
| dataVersion | версия или дата снимка данных | string | нет | до 50 симв. | `parking_zones.data_version` |
| featureCollection | GeoJSON FeatureCollection зон | object | да | — | — (не хранится) |

Если обязательное поле не передано или не проходит проверку — ответ 400 с перечнем полей в `errors`. Лишние поля отклоняются (`additionalProperties: false`).

### Пример запроса

```http
POST /api/v1/zone-imports HTTP/1.1
Host: localhost:8080
Authorization: Bearer <token>
Content-Type: application/json

{
  "dataSource": "open_data",
  "dataVersion": "строка",
  "featureCollection": {}
}
```

### Кому разрешено вызывать метод

- Диспетчер (`dispatcher`)

Остальным ролям — ответ 403.

## 4. Описание алгоритма работы метода

**Основной сценарий:**

1. Проверить GeoJSON FeatureCollection
2. Для каждой зоны проверить полигон ST_IsValid и номер
3. Валидные зоны вставить или обновить по zoneNumber, невалидные — пропустить с причиной
4. Вернуть imported, skipped и ошибки по номерам зон

**Сценарий исключений:**

- Файл не GeoJSON FeatureCollection → 422
- Все зоны невалидны → 422 invalid-zone-geometry

**Проверки и валидации:**

- `dataSource`: `open_data`, `demo`; по умолчанию `open_data`, обязательно
- `dataVersion`: до 50 симв.

**Кэширование:** не применяется.

**Производительность:** таймаут обработки 30 с.
